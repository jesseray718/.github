# Contributing

Thank you for improving an OpenRoot-related project.

## Contribution standard

Prefer small, specific, reviewable contributions. State:

- What problem is being addressed
- Which repository and component are affected
- What evidence, source, test, calculation, or measurement supports the change
- What remains uncertain or unverified
- How another contributor can reproduce the result

## Hardware work

For physical-system work, do not present an idea, simulation, or isolated observation as field-proven performance. Include relevant:

- Materials and dimensions
- Build conditions and tools
- Safety constraints
- Test method and measured results
- Known limitations and unanswered questions

## Software work

For code changes:

- Keep changes scoped
- Add or update tests where practical
- Document local setup and verification commands
- Do not commit credentials, local databases, logs, generated handoffs, or machine-specific runtime state
- Do not automate commits, pushes, releases, or external actions without explicit human approval

## License

Contributions are accepted under the license already declared by the target repository.
