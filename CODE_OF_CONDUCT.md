# Code of Conduct

OpenRoot-related projects welcome constructive collaboration across software, hardware, fabrication, research, documentation, and field practice.

## Expected behavior

- Be respectful and specific
- Distinguish evidence from speculation
- Give credit for work and sources
- Discuss safety concerns directly
- Accept correction when new evidence appears
- Avoid harassment, threats, discrimination, doxxing, or bad-faith disruption

## Enforcement

Report serious concerns privately to the repository maintainer. Maintainers may remove, edit, or reject contributions that violate these expectations.
